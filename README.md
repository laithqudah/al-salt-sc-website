# Al-Salt SC Website Mockup

Static Arabic-first website mockup for Al-Salt Sports Club.

## Notes

- This is not an official club publication.
- The mockup uses a publicly available Al-Salt SC logo image for presentation purposes.
- Logo, match data, staff/player lists, sponsors, and official contact channels should be approved by the club before public deployment.

## Files

- `index.html` - main website
- `styles.css` - visual styling
- `script.js` - mobile menu and header behaviour
- `assets/al-salt-logo-transparent.png` - transparent PNG logo asset used in the mockup

## Public facts used

- Al-Salt Sports Club is listed as founded in 1965.
- The club is based in As-Salt, Balqa Governorate, Jordan.
- Public football databases list Al-Salt in Jordanian professional football.
- Recent public records list Division 1 2017-18, AFC Cup 2021, and Jordan Shield Cup 2024-25 as major milestones.
